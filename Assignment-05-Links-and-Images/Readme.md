# Assignment 05: Creating an About Me Web Page

## Aim
To create a personal profile web page using basic HTML elements.

## Theory

### 1. Personal Profile
An About Me page presents information such as a person's introduction, education, interests, skills, and goals.

### 2. HTML Content Elements
Headings organize sections, paragraphs present descriptions, lists display skills or hobbies, and images can be used for profile photographs.

### 3. Page Organization
Content should follow a logical hierarchy so visitors can understand the information easily.

### 4. Semantic HTML
Elements such as `<header>`, `<main>`, `<section>`, and `<footer>` give page content meaningful structure.

## Tasks
1. Create a personal introduction.
2. Include relevant details such as education, interests, and skills.
3. Organize the information using headings, paragraphs, lists, and images where appropriate.

## Conclusion
This assignment applies basic HTML concepts to build a structured personal profile page.
