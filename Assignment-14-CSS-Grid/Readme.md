# Assignment 14: Responsive Layouts with Flexbox and Grid

## Aim
To combine Flexbox, CSS Grid, and media queries to create adaptable web layouts.

## Theory

### 1. Combining Layout Systems
Flexbox and Grid can be combined to organize different parts of a page. Grid can define the overall structure, while Flexbox can align elements inside individual sections.

### 2. Responsive Grid
The number and size of grid columns can change according to the available viewport width.

### 3. Responsive Flexbox
Flexbox items can wrap onto additional lines when `flex-wrap: wrap` is applied.

### 4. Breakpoints
Breakpoints are viewport sizes at which a design changes to maintain readability and usability. They should be chosen according to the layout's needs.

### 5. Consistent Spacing
CSS variables and the `gap` property help maintain consistent spacing across sections and screen sizes.

## Tasks
1. Build a layout using Flexbox and Grid.
2. Use media queries to adapt the layout.
3. Check alignment, spacing, and content flow on different screen sizes.

## Conclusion
This assignment applies multiple CSS layout techniques to create maintainable and responsive page structures.
