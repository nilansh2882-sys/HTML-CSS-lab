# Assignment 01: Introduction to Git and GitHub

## Aim
To understand version control and learn how to manage project files using Git and GitHub.

## Theory

### 1. Git
Git is a distributed version control system that tracks changes in source code and helps developers maintain different versions of a project.

### 2. GitHub
GitHub is an online platform for hosting Git repositories, collaborating with other developers, and sharing projects.

### 3. Common Git Commands
- `git init`: Initializes a Git repository.
- `git add`: Stages files for a commit.
- `git commit`: Saves a snapshot of staged changes.
- `git status`: Displays the current repository status.
- `git push`: Uploads local commits to a remote repository.
- `git pull`: Fetches and integrates remote changes.

### 4. Repository
A repository stores project files and their version history. It may be local or hosted on a platform such as GitHub.

## Tasks
1. Create or initialize a Git repository.
2. Track and commit project files.
3. Upload the project to GitHub.

## Conclusion
This assignment introduces version control and the basic workflow for publishing projects using Git and GitHub.
