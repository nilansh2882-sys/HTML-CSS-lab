# Assignment 07: HTML Tables

## Aim
To learn how to represent structured data using HTML tables.

## Theory

### 1. Table Structure
The `<table>` element defines a table. Common elements include:
- `<tr>`: Table row.
- `<th>`: Header cell.
- `<td>`: Data cell.
- `<thead>`: Groups header rows.
- `<tbody>`: Groups the main data rows.
- `<tfoot>`: Groups footer rows.

### 2. Rows and Columns
Rows organize data horizontally, while columns organize related values vertically.

### 3. Rowspan and Colspan
The `rowspan` attribute allows a cell to span multiple rows. The `colspan` attribute allows a cell to span multiple columns.

### 4. Table Styling
CSS can control borders, spacing, alignment, colors, and dimensions to improve readability.

## Tasks
1. Create a table with headings and data.
2. Organize information into rows and columns.
3. Use suitable table formatting and cell spanning where required.

## Conclusion
This assignment explains how to display structured information using HTML tables.
