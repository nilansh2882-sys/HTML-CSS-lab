# Assignment 11: CSS Flexbox

## Aim
To understand the Flexbox layout system and arrange elements in flexible rows or columns.

## Theory

### 1. Flexbox
CSS Flexbox is a one-dimensional layout system used to arrange items along a main axis and a cross axis.

### 2. Flex Container
Setting `display: flex` makes an element a flex container. Its direct children become flex items.

### 3. Main Properties
- `flex-direction`: Sets the main direction.
- `justify-content`: Aligns items along the main axis.
- `align-items`: Aligns items along the cross axis.
- `flex-wrap`: Controls whether items wrap onto additional lines.
- `gap`: Sets spacing between items.

### 4. Flex Item Properties
Properties such as `flex-grow`, `flex-shrink`, and `flex-basis` control how items use available space.

### 5. Practical Uses
Flexbox is useful for navigation bars, centered content, button groups, and responsive card rows.

## Tasks
1. Create a flex container.
2. Align and space items using Flexbox properties.
3. Build a layout that adapts to available space.

## Conclusion
This assignment demonstrates how Flexbox simplifies alignment, distribution, and one-dimensional page layouts.
