# Assignment 15: Complete Responsive Web Page

## Aim
To combine HTML and CSS concepts into a complete, responsive website.

## Theory

### 1. HTML Structure
HTML provides the content and organization of a web page. Semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` help describe the purpose of different regions.

### 2. CSS Styling
CSS controls the appearance of the website through typography, colors, spacing, borders, and layout rules.

### 3. Layout Techniques
Flexbox and Grid provide flexible ways to arrange content. The CSS box model controls element dimensions and spacing.

### 4. Responsive Design
Media queries, flexible dimensions, and responsive layout rules allow the website to adapt to different viewport sizes.

### 5. Accessibility and Usability
Clear headings, descriptive links, suitable color contrast, and alternative text for meaningful images improve accessibility and usability.

### 6. Testing
A web page should be checked for broken links, missing images, layout problems, and readability at different screen sizes.

## Tasks
1. Build a complete page using HTML.
2. Apply CSS styling and layout techniques.
3. Make the page responsive.
4. Test the final page in a browser.

## Conclusion
This assignment brings together HTML structure, CSS styling, layout systems, and responsive design to produce a complete web page.
