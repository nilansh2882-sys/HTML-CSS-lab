# Assignment 03: Div Elements and HTML Attributes

## Aim
To understand the `<div>` element and the use of HTML attributes.

## Theory

### 1. The Div Element
The `<div>` element is a generic block-level container used to group HTML content. It is commonly used to organize page sections and apply CSS styles.

### 2. HTML Attributes
Attributes provide additional information about an element. They are generally written in the opening tag.

Examples include:
- `id`: Identifies a particular element.
- `class`: Groups elements for styling or scripting.
- `title`: Provides advisory information.
- `style`: Applies inline CSS.
- `href`: Specifies a link destination.
- `src`: Specifies a resource location.

### 3. ID and Class
An `id` should uniquely identify an element within a document. A `class` can be shared by multiple elements.

### 4. Semantic Organization
Meaningful grouping makes HTML easier to read, style, and maintain. Semantic elements such as `<header>`, `<main>`, and `<footer>` may be used when appropriate.

## Tasks
1. Create content containers using `<div>`.
2. Apply relevant HTML attributes.
3. Organize related content into sections.

## Conclusion
This assignment explains how containers and attributes help organize HTML content and prepare it for styling.
