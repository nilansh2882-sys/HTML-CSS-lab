# Assignment 04: Links, Images, and Lists

## Aim
To learn how to add hyperlinks, images, and lists to an HTML page.

## Theory

### 1. Hyperlinks
The `<a>` element creates a hyperlink. Its `href` attribute specifies the destination URL or file path.

### 2. Images
The `<img>` element embeds an image. Important attributes include:
- `src`: Image path or URL.
- `alt`: Alternative text describing the image.
- `width` and `height`: Image dimensions.

### 3. Unordered Lists
The `<ul>` element creates a bulleted list, and each list item is represented by `<li>`.

### 4. Ordered Lists
The `<ol>` element creates a numbered list. Each item is represented by `<li>`.

### 5. Accessibility
Descriptive link text and meaningful image alternative text improve usability, including for people using assistive technologies.

## Tasks
1. Create hyperlinks to relevant destinations.
2. Insert images using the `<img>` element.
3. Create ordered and unordered lists.

## Conclusion
This assignment demonstrates how to connect web pages, display images, and organize information into lists.
