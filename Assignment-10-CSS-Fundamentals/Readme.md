# Assignment 10: CSS Box Model and Cards

## Aim
To understand the CSS box model and create styled content cards.

## Theory

### 1. CSS Box Model
Every element is represented by a rectangular box consisting of:
- Content: The text, image, or other content.
- Padding: Space between content and border.
- Border: The boundary around the padding and content.
- Margin: Space outside the border.

### 2. Box Sizing
With `box-sizing: content-box`, declared width and height apply to the content box. With `box-sizing: border-box`, they include content, padding, and border.

### 3. Margins and Padding
Margins create space between elements, while padding creates space inside an element's border.

### 4. Cards
A card is a visual container used to present related content. It often includes padding, a border or shadow, rounded corners, and consistent spacing.

### 5. Borders and Shadows
Properties such as `border`, `border-radius`, and `box-shadow` can make cards visually distinct.

## Tasks
1. Demonstrate the CSS box model.
2. Apply margins, padding, borders, and sizing.
3. Create one or more styled content cards.

## Conclusion
This assignment explains element sizing and spacing and applies these concepts to reusable card layouts.
