# Assignment 02: Basic HTML Structure

## Aim
To understand the structure of an HTML document and create a basic web page.

## Theory

### 1. HTML
HTML stands for HyperText Markup Language. It defines the structure and content of web pages using elements and tags.

### 2. Basic Document Structure
An HTML document typically contains:
- `<!DOCTYPE html>`: Declares the document as HTML5.
- `<html>`: The root element.
- `<head>`: Contains metadata and the page title.
- `<title>`: Specifies the browser-tab title.
- `<body>`: Contains visible page content.

### 3. Headings and Paragraphs
The `<h1>` to `<h6>` elements represent headings of different levels. The `<p>` element defines a paragraph.

### 4. HTML Elements
Most HTML elements have an opening tag, content, and a closing tag. Some elements, such as `<br>` and `<img>`, are void elements and do not use closing tags.

## Tasks
1. Create a valid HTML document.
2. Add headings and paragraphs.
3. Display content in a browser.

## Conclusion
This assignment establishes the foundation for creating structured web pages using HTML.
