# Assignment 06: HTML Forms

## Aim
To understand HTML forms and collect user input through different form controls.

## Theory

### 1. Forms
The `<form>` element groups controls used to collect and submit user information.

### 2. Input Elements
The `<input>` element supports several types, including:
- `text`: Single-line text.
- `email`: Email address input.
- `password`: Password input.
- `number`: Numeric input.
- `radio`: Select one option from a group.
- `checkbox`: Select one or more options.
- `submit`: Submit form data.

### 3. Labels
The `<label>` element provides a description for a form control. Connecting labels to controls improves usability and accessibility.

### 4. Other Form Controls
`<textarea>` supports multiline text, while `<select>` and `<option>` provide dropdown choices.

### 5. Validation
Attributes such as `required`, `min`, `max`, and `maxlength` provide built-in browser validation for supported input types.

## Tasks
1. Create a form with suitable input fields.
2. Add labels and selection controls.
3. Apply appropriate validation attributes.

## Conclusion
This assignment demonstrates how HTML forms collect and validate user input.
