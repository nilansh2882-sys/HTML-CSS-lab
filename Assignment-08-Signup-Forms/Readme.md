# Assignment 08: Introduction to CSS

## Aim
To understand CSS and apply basic styling to HTML elements.

## Theory

### 1. CSS
CSS stands for Cascading Style Sheets. It controls the presentation and layout of HTML documents, including colors, fonts, spacing, and positioning.

### 2. Ways to Apply CSS
- Inline CSS: Uses the `style` attribute on an element.
- Internal CSS: Uses a `<style>` element within the HTML document.
- External CSS: Uses a separate `.css` file linked through `<link>`.

### 3. CSS Selectors
Selectors identify which HTML elements receive styling.
- Element selector: Targets elements by tag name.
- Class selector: Uses a period, such as `.card`.
- ID selector: Uses a hash, such as `#header`.

### 4. CSS Properties
Common properties include `color`, `background-color`, `font-size`, `font-family`, `text-align`, and `border`.

### 5. The Cascade
When CSS rules conflict, the browser considers factors such as importance, specificity, and source order to determine which declaration applies.

## Tasks
1. Apply styles to HTML elements.
2. Use different CSS selectors.
3. Experiment with colors, fonts, borders, and alignment.

## Conclusion
This assignment introduces the fundamental concepts required to style and customize web pages using CSS.
